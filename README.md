# ⛵ Jacht Log

A simple application for keeping a sailing logbook.

## 🧭 What is it for?

Jacht Log helps you record and organize your sailing trips:

* create trips (weekend cruises, holidays, regattas, etc.),
* add timestamped log entries,
* instantly view sailing, motoring, mooring times

Think of it as a digital version of a traditional yacht's logbook.

---

## ⬇️ Installation

1. Open the **Releases** section on GitHub.
2. Download the latest app version (file `app-release.apk`)
3. Open the Files app, visit the Download folder and run the downloaded file,

> If your system blocks the installation, make sure installation from unknown sources is allowed.

---

## 🚀 Getting Started

### 1. Create a new trip

* Click the menu icon (three horizontal lines) and select **"New Trip"**

### 2. Add log entries

* During the trip, record important events by taping the switch buttons "Engine", "Sail", etc.
* Event time is saved automatically, it can be changed later,

### 3. Finish the trip

* click the "Stop" icon - trip end time can be changed later,

### 4. Review previous trips

* Select a trip from the saved trips list by clicking on "Read trip",
* Browse its timeline and log entries,

---

## 📌 Tips

* Add entries as events happen whenever possible
* You can keep multiple trips; creating a new trip does not overwrite existing ones
* Dates and times for individual entries can be edited
